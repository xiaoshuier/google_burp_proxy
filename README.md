# Burp Proxy Switcher

一个简洁的 Chrome Manifest V3 插件，用域名规则控制 Burp Suite 或 SOCKS5 代理。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录。
4. 点击工具栏中的插件图标，填写 Burp 监听地址和端口。

## 规则

每行一条规则，例如：

```text
*google.com
*.example.com
```

匹配的域名会被过滤并返回 `DIRECT`，未匹配域名走配置的 Burp 代理。关闭开关或插件后，扩展会清除自身设置的系统代理。

代理类型可以选择 `HTTP / Burp` 或 `SOCKS5`。例如 SOCKS5 代理填写 `127.0.0.1:1080`。Chrome PAC 支持的是单个当前代理；如果需要多个代理按域名分流，需要为不同代理分别增加规则逻辑，不能简单把两个代理串在一起。

现在支持多个代理方案：在“配置代理”页面填写方案名称（如 `burp`、`xxx`）并保存，之后可直接在插件主页面选择方案。启用状态下切换方案会立即应用对应配置。

> Chrome 同一时间只能由一个扩展控制系统代理。如果其他代理插件正在运行，可能会互相覆盖。
